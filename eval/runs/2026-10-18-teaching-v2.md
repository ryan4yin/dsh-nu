# Teaching v2: bash-habit rewrites

Date: 2026-10-18

This round validates the compact and full guides after they gained an explicit
bash/PowerShell rewrite section. The section covers the refusals a session
review found in real use: `2>/dev/null`, `2>&1`, `2>file`, `&&`, `mkdir -p`,
`ls -R`, `for ...; do ...; done`, and `test -d`. It also reruns the
pre-change guides (main at 7e25397) as the baseline.

## What changed

| text | before | after |
|---|---:|---:|
| `compact.md` | 1,043 chars | 1,713 chars |
| `full.md` | 4,059 chars | 5,055 chars |
| compact-arm teaching text (rules + guide + tool description) | 4,704 chars | 5,374 chars |
| full-arm teaching text (rules + guide + tool description) | 7,720 chars | 8,716 chars |

The rules and the rewritten tool description are unchanged. Three eval cases
were added for the observed habits: `nested-dirs` (`mkdir -p`, `ls -R`),
`stderr-only` (`2>&1` / `2>/dev/null` tricks), and `sequence-after-failure`
(`&&`). The runner now has `--concurrency`; this round used 6.

## Method

- Actors: `gpt-6-luna` (openai route) and `ds41f`
  (`anthropic/workbuddy-ai/deepseek-v4.1-flash`).
- Each actor ran 12 cases x 2 arms (full, compact) x 3 samples = 72 samples, via a
  real `dsh 0.2.1-rc.2` boot with this branch's package, one headless run per
  sample.
- The pre-change run used the same cases, actors, arms, sample count, and
  runner, with the package built from commit 7e25397.
- Judges were cross-family: luna scored the ds41f samples, ds41f scored the luna
  samples, 72/72 each per version.
- Deterministic task success and preflight counts are the primary evidence;
  judge scores are directional.

## Refusals

Four samples out of 288 across both versions were refused, all on
`nested-dirs` except one, and all recovered on retry:

- ds41f, before, full and compact: `mkdir -p build/out/bin ...` (bash-flag).
- ds41f, after, full: `mkdir -p build/out/bin ...` (bash-flag).
- luna, after, compact, `stderr-discard`: `... 2> /dev/null` (stderr-file).

## Reading

- The rewrite did not reduce refusals on this case set: 2 before, 2 after. Both
  guides already name the same rewrites in different words; the models that used
  `mkdir -p` or `2> /dev/null` ignored both.
- Task success fell by 9 strict matches, scattered across answer-format cases
  (markdown-files, workdir-state, nested-dirs, pipeline-status, stderr-only,
  readiness-wait). No failure was a refused command; this is answer-format
  strictness and three-sample noise, not a shell regression.
- Judge score moved +0.08 toward the new text; the luna compact cell moved most
  (+0.19). Treat this as directional.
- Token cost is mixed: +3% for luna and +4% for ds41f full, +3% for luna compact,
  -6% for ds41f compact.
- The change rests on the real-session refusal mix, not on this synthetic gain;
  this round shows no clear cost and no clear win. Keep the default guide at
  `full`.
