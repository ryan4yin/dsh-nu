# Teaching v2: bash-habit rewrites

Date: 2026-10-18

This round validates the compact and full guides after they gained an explicit
bash/PowerShell rewrite section. The section covers the refusals a session
review found in real use: `2>/dev/null`, `2>&1`, `2>file`, `&&`, `mkdir -p`,
`ls -R`, `for ...; do ...; done`, and `test -d`.

## What changed

| text | before | after |

| `full.md` | 4,059 chars | 5,055 chars |
| compact-arm teaching text (rules + guide + tool description) | 4,704 chars | 5,374 chars |
| full-arm teaching text (rules + guide + tool description) | 7,720 chars | 8,716 chars |

The rules and the rewritten tool description are unchanged. Three eval cases
were added for the observed habits: `nested-dirs` (`mkdir -p`, `ls -R`),
`stderr-only` (`2>&1` / `2>/dev/null` tricks), and `sequence-after-failure`
(`&&`). The runner now has `--concurrency`; this round used 6.

## Method

- Actors: `gpt-6-luna` (openai route) and `ds41f`
  (`anthropic/workbuddy-ai/deepseek-v4.1-flash`).
- Each actor ran 12 cases x 2 arms (full, compact) x 3 samples = 72 samples, via a
  real `dsh 0.2.1-rc.2` boot with this branch's package, one headless run per
  sample.
- Judges were cross-family: luna scored the ds41f samples, ds41f scored the luna
  samples, 72/72 each.
- Deterministic task success and preflight counts are the primary evidence;
  judge scores are directional.

## Refusals

Two samples out of 144 were refused, both once, and both recovered on retry:

- ds41f, full, `nested-dirs`: `mkdir -p build/out/bin | ignore; glob build/**/* ...`
  (bash-flag).
- gpt-6-luna, compact, `stderr-discard`: `... 2> /dev/null` (stderr-file).

## Reading

- Compact is no worse than full on either actor and is cheaper: 15% fewer tokens
  for ds41f and 3% for luna. The luna judge preferred compact by 0.16.
- The rewrite section did not eliminate the habits: one `mkdir -p` and one
  `2> /dev/null` still appeared. Both models recovered, so the cost is one extra
  turn, not task failure.
- Task-success differences are answer-format strictness, not shell failures; the
  per-case table in the runner output shows which cells missed.
- Three samples per cell are directional. This round does not justify changing
  the default guide from `full`.

Raw samples stay under `.work/eval-out`; this file is the committed record.
